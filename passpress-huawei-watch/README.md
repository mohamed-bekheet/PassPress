# PassPress Huawei Wearable Watch App (`passpress-huawei-watch`)

This directory is dedicated to the Huawei Wearable / Smartwatch application for the **PassPress** system (HarmonyOS / Huawei Wear Engine / LiteOS app).

## Overview

The Huawei Wearable companion project aims to enable password management, authentication triggers, dynamic passkey displays, and BLE interaction directly from Huawei smartwatches (e.g. Huawei Watch GT series, Huawei Watch 3/4 series).

## Directory Structure

```
passpress-huawei-watch/
├── README.md               # Quick start & documentation
├── docs/                   # Design notes, API specifications & specs
└── src/                    # Wearable application source code
```

## Setup & Prerequisites

- **IDE**: Huawei DevEco Studio
- **SDK**: HarmonyOS SDK / Wear Engine SDK
- **Target Devices**: Huawei Watch (HarmonyOS / LiteOS)

## Getting Started

1. Open DevEco Studio and import/create the wearable app project in `src/`.
2. Configure permissions for Bluetooth / BLE capabilities.
3. Build and deploy to a connected Huawei wearable device or simulator.
